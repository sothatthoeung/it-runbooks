## 📐 Runbook Structure

Every entry in this repository adheres to the following documentation standard:

1. **Metadata:** Unique Issue ID, Environment, Severity, and Incident Date.
2. **Symptoms & Error Signature:** Observable faults, log snippets, and exception traces.
3. **Root Cause Analysis (RCA):** Deep-dive explanation of the underlying failure mechanism.
4. **Step-by-Step Resolution:** Segmented procedures for Administrators and End-Users.
5. **Prevention & Hardening:** Architectural or policy changes to eliminate recurrence.
